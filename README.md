# Resume Screening System

AI-powered Resume Screening System using:

- Streamlit
- FastAPI
- NLP
- TF-IDF Similarity
- Skill Extraction

## Features

- Resume Parsing
- Skill Matching
- Missing Skills Detection
- Match Score Visualization
- FastAPI Backend
- Streamlit Frontend

## Run Streamlit

```bash
streamlit run app/streamlit_app.py
```

## Run FastAPI

```bash
uvicorn app.fastapi_app:app --reload
```
